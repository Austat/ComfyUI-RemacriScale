Installation

Method 1: Clone the Repository Navigate to your ComfyUI custom_nodes directory. Run:

git clone https://github.com/Austat/ComfyUI-RemacriScale

cd ComfyUI-RemacriScale
pip install -r requirements.txt

Restart ComfyUI.
